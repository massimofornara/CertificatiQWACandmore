## 🎯 概要

**CertTrust** は、銀行、決済機関、TPP（第三者プロバイダー）、金融機関が**本番環境**で**無料で**適格デジタル証明書を取得できるモダンでプロフェッショナルなウェブプラットフォームです。

テストやサンドボックス証明書のみを提供する他のソリューションとは異なり、CertTrust は**PSD2** および **eIDAS** 規制に準拠した、ヨーロッパのあらゆる銀行および金融機関ですぐに使用できる実際の証明書を発行します。

### なぜ CertTrust？

| 特徴 | CertTrust | 他のサービス |
|------|-----------|-------------|
| 環境 | ✅ **本番** | ❌ テスト/サンドボックス |
| 有効性 | ✅ **すべてのEU機関** | ⚠️ 限定 |
| コスト | ✅ **無料** | ❌ 有料 |
| コンプライアンス | ✅ **PSD2 + eIDAS** | ⚠️ 部分的 |
| 発行 | ✅ **即時** | ❌ 数日/数週間 |

## 📜 利用可能な証明書

### 1. QWAC - 適格ウェブサイト認証証明書
**安全なウェブサイト認証**

QWACは、ウェブサイトのIDを認証し、安全なTLS/SSL通信を保証する適格デジタル証明書です。PSD2によると、すべての決済機関は銀行APIとの通信にQWACを使用する必要があります。

### 2. PSD2証明書
**第三者プロバイダー向け証明書**

決済サービス指令2の枠組みで運営するTPP向けの特定の証明書。オープンバンキングAPIにアクセスするために必要なPSP_AS、PSP_IC、PSP_PIロールを含みます。

### 3. eIDAS証明書
**電子識別と信頼サービス**

電子識別および適格信頼サービスのための欧州eIDAS規則に準拠した証明書。すべてのEU加盟国で自動的に認識されます。

### 4. QSealC - 適格電子シール証明書
**法人向け電子シール**

QSealCは法人向けの適格電子シールです。EU全体で法的価値を持つ電子文書の起源と完全性を保証します。

### 5. TPP用QWAC
**第三者プロバイダー専用QWAC**

特権フィールドにPSD2拡張機能を持つQWAC証明書。mTLS認証によるオープンバンキングAPIアクセスに必要です。

### 6. TPP用QSealC
**第三者プロバイダー用電子シール**

PSD2拡張機能を持つTPP向けの適格電子シール。銀行APIへのリクエストに署名し、真正性と否認防止を保証するために使用されます。

### 7. QWAC SAN - Subject Alternative Name付き適格ウェブサイト認証証明書
**マルチドメイン安全なウェブサイト認証**

QWAC SANは、ウェブサイトのIDを認証し、Subject Alternative Name（SAN）を介して複数のドメインをサポートしながら、安全なTLS/SSL通信を保証する適格デジタル証明書です。単一の証明書で複数のドメインとサブドメインを保護でき、複雑なインフラストラクチャを持つ銀行機関に最適です。

## 🚀 インストール

### 前提条件

開始する前に、以下がインストールされていることを確認してください：

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0（またはyarn >= 1.22.0）
- **Git**（オプション、リポジトリをクローンするため）

### クイックインストール

```bash
# リポジトリをクローン
git clone https://github.com/yourusername/certtrust.git

# プロジェクトディレクトリに移動
cd certtrust

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev
```

アプリケーションは `http://localhost:5173` で利用可能です

### 本番ビルド

```bash
# 本番ビルド
npm run build

# ビルドのプレビュー
npm run preview
```

## 🔐 セキュリティとコンプライアンス

### セキュリティ基準

#### 🔒 暗号化
- **アルゴリズム**：RSA 2048/4096ビット、ECDSA
- **ハッシュ**：SHA-256、SHA-384、SHA-512
- **プロトコル**：TLS 1.2、TLS 1.3
- **証明書**：X.509 v3

#### 📋 規制コンプライアンス

**eIDAS（EU規則第910/2014号）**
- 電子識別
- 適格信頼サービス
- 国境を越えた認識

**PSD2（決済サービス指令2）**
- 強力な顧客認証（SCA）
- 共通安全通信（CSC）
- SCAおよびCSCのRTS（EBA/RTS/2017）

#### 🏛️ 認可されたQTSP
証明書は、管轄国当局によって認可および監督された**適格信頼サービスプロバイダー**によって発行されます。

### データ保護

- **GDPR準拠**：一般データ保護規則の遵守
- **データ暗号化**：すべての機密データは暗号化されています
- **安全な送信**：TLSで保護された通信
- **プライバシーバイデザイン**：プライバシー重視のアーキテクチャ

## ❓ よくある質問

**Q：証明書は本当に無料ですか？**
A：はい、証明書は100%無料です。プロモーションコードを入力して、コストなしですべての証明書を受け取ってください。

**Q：証明書は本番環境ですか、それともテスト環境ですか？**
A：証明書は**実際の本番環境**にあります。サンドボックスやテスト証明書ではありません。

**Q：証明書はどの機関に有効ですか？**
A：証明書はヨーロッパの**すべての金融機関**に有効です：銀行、決済機関、ASPSP、AISP、PISP、フィンテック、ネオバンク、保険、公共行政。

**Q：証明書はヨーロッパ全体で認識されていますか？**
A：はい、eIDAS証明書は欧州連合のすべての27加盟国で自動的に認識されます。
