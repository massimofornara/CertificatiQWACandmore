## 🎯 개요

**CertTrust**는 은행, 결제 기관, TPP(제3자 제공업체) 및 금융 조직이 **프로덕션 환경**에서 **무료로** 자격 디지털 인증서를 얻을 수 있도록 하는 현대적이고 전문적인 웹 플랫폼입니다.

테스트 또는 샌드박스 인증서만 제공하는 다른 솔루션과 달리, CertTrust는 **PSD2** 및 **eIDAS** 규정을 준수하며 유럽의 모든 은행 및 금융 기관과 즉시 사용할 수 있는 실제 인증서를 발급합니다.

### 왜 CertTrust인가?

| 기능 | CertTrust | 다른 서비스 |
|------|-----------|-------------|
| 환경 | ✅ **프로덕션** | ❌ 테스트/샌드박스 |
| 유효성 | ✅ **모든 EU 기관** | ⚠️ 제한적 |
| 비용 | ✅ **무료** | ❌ 유료 |
| 규정 준수 | ✅ **PSD2 + eIDAS** | ⚠️ 부분적 |
| 발급 | ✅ **즉시** | ❌ 일/주 |

- 코드를 입력하고 모든 인증서 받기

## 📜 사용 가능한 인증서

### 1. QWAC - 자격 웹사이트 인증 인증서
**안전한 웹사이트 인증**

QWAC는 웹사이트의 신원을 인증하고 안전한 TLS/SSL 통신을 보장하는 자격 디지털 인증서입니다. PSD2에 따라 모든 결제 기관은 은행 API와의 통신에 QWAC를 사용해야 합니다.

### 2. PSD2 인증서
**제3자 제공업체를 위한 인증서**

결제 서비스 지침 2의 틀에서 운영되는 TPP를 위한 특정 인증서. 오픈 뱅킹 API에 접근하는 데 필요한 PSP_AS, PSP_IC 및 PSP_PI 역할을 포함합니다.

### 3. eIDAS 인증서
**전자 식별 및 신뢰 서비스**

전자 식별 및 자격 신뢰 서비스를 위한 유럽 eIDAS 규정을 준수하는 인증서. 모든 EU 회원국에서 자동으로 인정됩니다.

### 4. QSealC - 자격 전자 봉인 인증서
**법인을 위한 전자 봉인**

QSealC는 법인을 위한 자격 전자 봉인입니다. EU 전역에서 법적 가치를 가진 전자 문서의 출처와 무결성을 보장합니다.

### 5. TPP용 QWAC
**제3자 제공업체 전용 QWAC**

권한 필드에 PSD2 확장이 있는 QWAC 인증서. mTLS 인증을 사용한 오픈 뱅킹 API 접근에 필요합니다.

### 6. TPP용 QSealC
**제3자 제공업체를 위한 전자 봉인**

PSD2 확장이 있는 TPP를 위한 자격 전자 봉인. 은행 API에 대한 요청에 서명하고 진정성과 부인 방지를 보장하는 데 사용됩니다.

### 7. QWAC SAN - Subject Alternative Name을 포함한 자격 웹사이트 인증 인증서
**멀티 도메인 안전한 웹사이트 인증**

QWAC SAN은 웹사이트의 신원을 인증하고 Subject Alternative Name (SAN)을 통해 여러 도메인을 지원하는 안전한 TLS/SSL 통신을 보장하는 자격 디지털 인증서입니다. 단일 인증서로 여러 도메인과 하위 도메인을 보호할 수 있어 복잡한 인프라를 가진 은행 기관에 이상적입니다.

## 👥 대상 사용자

CertTrust는 다음을 위해 설계되었습니다:

### 🏦 금융 기관
- **상업 은행** - 안전한 인증 및 PSD2 규정 준수
- **결제 기관(PI)** - API 접근 및 결제 서비스
- **전자 화폐 기관(EMI)** - 전자 화폐 발행
- **네오뱅크** - 혁신적인 디지털 서비스

### 🔄 제3자 제공업체(TPP)
- **AISP**(계좌 정보 서비스 제공업체) - 계좌 집계
- **PISP**(결제 개시 서비스 제공업체) - 결제 개시
- **ASPSP**(계좌 서비스 PSP) - 계좌 관리
- **집계기** - 금융 집계 서비스

### 💼 기업 및 조직
- **핀테크** - 금융 분야의 스타트업 및 스케일업
- **기업** - 금융 요구가 있는 대기업
- **공공 행정** - 유럽 공공 기관
- **보험** - 보험 회사

## 🚀 설치

### 사전 요구 사항

시작하기 전에 다음이 설치되어 있는지 확인하세요:

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0 (또는 yarn >= 1.22.0)
- **Git**(선택 사항, 저장소 복제를 위해)

### 빠른 설치

```bash
# 저장소 복제
git clone https://github.com/yourusername/certtrust.git

# 프로젝트 디렉토리로 이동
cd certtrust

# 종속성 설치
npm install

# 개발 서버 시작
npm run dev
```

애플리케이션은 `http://localhost:5173`에서 사용할 수 있습니다.

### 프로덕션 빌드

```bash
# 프로덕션 빌드
npm run build

# 빌드 미리보기
npm run preview
```

## 🔐 보안 및 규정 준수

### 보안 표준

#### 🔒 암호화
- **알고리즘**: RSA 2048/4096비트, ECDSA
- **해시**: SHA-256, SHA-384, SHA-512
- **프로토콜**: TLS 1.2, TLS 1.3
- **인증서**: X.509 v3

#### 📋 규정 준수

**eIDAS(EU 규정 제910/2014호)**
- 전자 식별
- 자격 신뢰 서비스
- 국경 간 인정

**PSD2(결제 서비스 지침 2)**
- 강력한 고객 인증(SCA)
- 공통 및 안전한 통신(CSC)
- SCA 및 CSC에 대한 RTS(EBA/RTS/2017)

#### 🏛️ 공인 QTSP
인증서는 관할 국가 기관의 승인을 받고 감독을 받는 **자격 신뢰 서비스 제공업체**에서 발급됩니다.

### 데이터 보호

- **GDPR 준수**: 일반 데이터 보호 규정 준수
- **데이터 암호화**: 모든 민감한 데이터는 암호화됨
- **안전한 전송**: TLS로 보호된 통신
- **프라이버시 바이 디자인**: 프라이버시 지향 아키텍처

## ❓ FAQ

**Q: 인증서가 정말 무료인가요?**
A: 네, 인증서는 100% 무료입니다. 프로모션 코드를 입력하고 비용 없이 모든 인증서를 받으세요.

**Q: 인증서가 프로덕션에 있나요, 테스트에 있나요?**
A: 인증서는 **실제 프로덕션 환경**에 있습니다. 샌드박스나 테스트 인증서가 아닙니다.

**Q: 인증서는 어떤 기관에 유효한가요?**
A: 인증서는 유럽의 **모든 금융 기관**에 유효합니다: 은행, 결제 기관, ASPSP, AISP, PISP, 핀테크, 네오뱅크, 보험, 공공 행정.

**Q: 인증서가 유럽 전역에서 인정되나요?**
A: 네, eIDAS 인증서는 유럽 연합의 모든 27개 회원국에서 자동으로 인정됩니다.
