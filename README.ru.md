## 🎯 Обзор

**CertTrust** — это современная профессиональная веб-платформа, позволяющая банкам, платёжным учреждениям, TPP (сторонним поставщикам) и финансовым организациям **бесплатно** получать квалифицированные цифровые сертификаты в **производственной среде**.

В отличие от других решений, которые предоставляют только тестовые или песочные сертификаты, CertTrust выпускает реальные сертификаты, готовые к немедленному использованию с любым банковским и финансовым учреждением в Европе, соответствующие регламентам **PSD2** и **eIDAS**.

## 📜 Доступные Сертификаты

### 1. QWAC - Квалифицированный Сертификат Аутентификации Веб-Сайта
**Безопасная аутентификация веб-сайта**

QWAC — это квалифицированный цифровой сертификат, который аутентифицирует идентичность веб-сайта и гарантирует безопасные коммуникации TLS/SSL. Согласно PSD2, все платёжные учреждения должны использовать QWAC для коммуникаций с банковскими API.

### 2. Сертификаты PSD2
**Сертификаты для сторонних поставщиков**

Специальные сертификаты для TPP, работающих в рамках Директивы о платёжных услугах 2. Включают роли PSP_AS, PSP_IC и PSP_PI, необходимые для доступа к API открытого банкинга.

### 3. Сертификаты eIDAS
**Электронная Идентификация и Доверенные Услуги**

Сертификаты, соответствующие европейскому регламенту eIDAS для электронной идентификации и квалифицированных доверенных услуг. Автоматически признаются во всех государствах-членах ЕС.

### 4. QSealC - Квалифицированный Сертификат Электронной Печати
**Электронная печать для юридических лиц**

QSealC — это квалифицированная электронная печать для юридических лиц. Гарантирует происхождение и целостность электронных документов с юридической силой во всём ЕС.

### 5. QWAC для TPP
**QWAC специально для сторонних поставщиков**

Сертификат QWAC с расширениями PSD2 в полях привилегий. Требуется для доступа к API открытого банкинга с аутентификацией mTLS.

### 6. QSealC для TPP
**Электронная печать для сторонних поставщиков**

Квалифицированная электронная печать для TPP с расширениями PSD2. Используется для подписания запросов к банковским API и гарантии подлинности и неотказуемости.

## 🚀 Установка

### Предварительные Требования

Перед началом убедитесь, что у вас установлено:

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0 (или yarn >= 1.22.0)
- **Git** (опционально, для клонирования репозитория)

### Быстрая Установка

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/certtrust.git

# Перейти в директорию проекта
cd certtrust

# Установить зависимости
npm install

# Запустить сервер разработки
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### Сборка для Продакшн

```bash
# Сборка для продакшн
npm run build

# Предпросмотр сборки
npm run preview
```

## 🔐 Безопасность и Соответствие

### Стандарты Безопасности

#### 🔒 Шифрование
- **Алгоритмы**: RSA 2048/4096 бит, ECDSA
- **Хэш**: SHA-256, SHA-384, SHA-512
- **Протоколы**: TLS 1.2, TLS 1.3
- **Сертификаты**: X.509 v3

#### 📋 Нормативное Соответствие

**eIDAS (Регламент ЕС № 910/2014)**
- Электронная идентификация
- Квалифицированные доверенные услуги
- Трансграничное признание

**PSD2 (Директива о Платёжных Услугах 2)**
- Сильная Аутентификация Клиента (SCA)
- Общая и Безопасная Коммуникация (CSC)
- RTS по SCA и CSC (EBA/RTS/2017)

#### 🏛️ Авторизованные QTSP
Сертификаты выпускаются **квалифицированными поставщиками доверенных услуг**, авторизованными и контролируемыми компетентными национальными органами.

### Защита Данных

- **GDPR Соответствие**: Соблюдение Общего Регламента по Защите Данных
- **Шифрование Данных**: Все конфиденциальные данные зашифрованы
- **Безопасная Передача**: Коммуникации защищены TLS
- **Privacy by Design**: Архитектура, ориентированная на конфиденциальность

## ❓ FAQ

**В: Сертификаты действительно бесплатны?**
О: Да, сертификаты на 100% бесплатны. Введите промокод и получите все сертификаты без каких-либо затрат.

**В: Сертификаты в продакшн или в тесте?**
О: Сертификаты находятся в **реальной производственной среде**. Это не песочные или тестовые сертификаты.

**В: Для каких учреждений действительны сертификаты?**
О: Сертификаты действительны для **каждого финансового учреждения** в Европе: банки, платёжные учреждения, ASPSP, AISP, PISP, финтех, необанки, страхование, государственное управление.

**В: Сертификаты признаются по всей Европе?**
О: Да, сертификаты eIDAS автоматически признаются во всех 27 государствах-членах Европейского Союза.
