## 📜 可用证书

### 1. QWAC - 合格网站认证证书
**安全的网站认证**

QWAC 是一种合格的数字证书，用于认证网站身份并保证安全的 TLS/SSL 通信。根据 PSD2，所有支付机构必须使用 QWAC 与银行 API 通信。

### 2. PSD2 证书
**第三方提供商证书**

为在支付服务指令 2 框架下运营的 TPP 提供的特定证书。包括访问开放银行 API 所需的 PSP_AS、PSP_IC 和 PSP_PI 角色。

### 3. eIDAS 证书
**电子身份识别与信任服务**

符合欧洲 eIDAS 法规的电子身份识别和合格信任服务证书。在所有欧盟成员国自动认可。

### 4. QSealC - 合格电子印章证书
**法人电子印章**

QSealC 是法人的合格电子印章。保证电子文件的来源和完整性，在整个欧盟具有法律效力。

### 5. TPP 专用 QWAC
**第三方提供商专用 QWAC**

在权限字段中具有 PSD2 扩展的 QWAC 证书。需要用于具有 mTLS 认证的开放银行 API 访问。

### 6. TPP 专用 QSealC
**第三方提供商电子印章**

具有 PSD2 扩展的 TPP 合格电子印章。用于签署银行 API 请求并保证真实性和不可否认性。

### 7. QWAC SAN - 带有主题备用名称的合格网站认证证书
**多域名安全网站认证**

QWAC SAN 是一种合格的数字证书，用于认证网站身份并保证安全的 TLS/SSL 通信，支持通过主题备用名称 (SAN) 支持多个域名。允许使用单个证书保护多个域名和子域名，非常适合具有复杂基础设施的银行机构。

## 🚀 安装

### 先决条件

开始之前，请确保已安装：

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0（或 yarn >= 1.22.0）
- **Git**（可选，用于克隆仓库）

### 快速安装

```bash
# 克隆仓库
git clone https://github.com/yourusername/certtrust.git

# 进入项目目录
cd certtrust

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

应用程序将在 `http://localhost:5173` 可用

### 生产构建

```bash
# 生产构建
npm run build

# 预览构建
npm run preview
```

## 🔐 安全与合规

### 安全标准

#### 🔒 加密
- **算法**：RSA 2048/4096 位，ECDSA
- **哈希**：SHA-256、SHA-384、SHA-512
- **协议**：TLS 1.2、TLS 1.3
- **证书**：X.509 v3

#### 📋 监管合规

**eIDAS（欧盟法规第 910/2014 号）**
- 电子身份识别
- 合格信任服务
- 跨境认可

- 强客户认证 (SCA)
