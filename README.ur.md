## 🎯 جائزہ

**CertTrust** ایک جدید، پیشہ ورانہ ویب پلیٹ فارم ہے جو بینکوں، ادائیگی کے اداروں، TPP (تھرڈ پارٹی فراہم کنندگان) اور مالیاتی تنظیموں کو **پروڈکشن ماحول** میں **مفت** اہل ڈیجیٹل سرٹیفکیٹس حاصل کرنے کی اجازت دیتا ہے۔

دیگر حل کے برعکس جو صرف ٹیسٹ یا سینڈ باکس سرٹیفکیٹس فراہم کرتے ہیں، CertTrust حقیقی سرٹیفکیٹس جاری کرتا ہے، جو یورپ میں کسی بھی بینکنگ اور مالیاتی ادارے کے ساتھ فوری استعمال کے لیے تیار ہیں، **PSD2** اور **eIDAS** ضوابط کے مطابق۔

### CertTrust کیوں؟

| خصوصیت | CertTrust | دیگر خدمات |
|---------|-----------|------------|
| ماحول | ✅ **پروڈکشن** | ❌ ٹیسٹ/سینڈ باکس |
| قابلیت | ✅ **ہر EU ادارہ** | ⚠️ محدود |
| لاگت | ✅ **مفت** | ❌ ادائیگی |
| تعمیل | ✅ **PSD2 + eIDAS** | ⚠️ جزوی |
| اجراء | ✅ **فوری** | ❌ دن/ہفتے |

## ✨ اہم خصوصیات

### 🏭 حقیقی پروڈکشن ماحول
- سرٹیفکیٹس پروڈکشن میں جاری کیے گئے، ٹیسٹ ماحول میں نہیں
- حقیقی بینکنگ APIs کے ساتھ فوری استعمال کے لیے تیار
- یورپی یونین بھر میں مکمل قانونی قدر

### 🏦 عالمی قابلیت
- یورپ کے **تمام مالیاتی اداروں** نے قبول کیا
- تجارتی بینک، ادائیگی کے ادارے، ASPSP، AISP، PISP
- فن ٹیک، نیو بینک، انشورنس، عوامی انتظامیہ

### ⚡ فوری اجراء
- منٹوں میں سرٹیفکیٹس وصول کریں
- کوئی طویل منظوری کا عمل نہیں
- کوڈ کی توثیق کے بعد فوری ڈاؤن لوڈ

### 🔒 زیادہ سے زیادہ سیکیورٹی
- 2048/4096 بٹس کرپٹوگرافک کیز
- SHA-256 اور اس سے اوپر کے الگورتھم
- مجاز QTSP (اہل ٹرسٹ سروس فراہم کنندہ) نے جاری کیا

### 🇪🇺 یورپی تعمیل
- eIDAS ریگولیشن (EU) نمبر 910/2014 کے ساتھ 100% مطابقت
- PSD2 (ادائیگی خدمات ہدایت 2) کے ساتھ مکمل تعمیل
- EBA (یورپی بینکنگ اتھارٹی) معیارات کی پابندی

### 💰 100% مفت
- کوئی چھپی ہوئی لاگت نہیں
- کوئی سبسکرپشن نہیں
- کوڈ درج کریں اور تمام سرٹیفکیٹس حاصل کریں

## 📜 دستیاب سرٹیفکیٹس

### 1. QWAC - اہل ویب سائٹ تصدیق سرٹیفکیٹ
**محفوظ ویب سائٹ تصدیق**

QWAC ایک اہل ڈیجیٹل سرٹیفکیٹ ہے جو ویب سائٹ کی شناخت کی تصدیق کرتا ہے اور محفوظ TLS/SSL مواصلات کی ضمانت دیتا ہے۔

### 2. PSD2 سرٹیفکیٹس
**تھرڈ پارٹی فراہم کنندگان کے لیے سرٹیفکیٹس**

ادائیگی خدمات ہدایت 2 کے تحت کام کرنے والے TPPs کے لیے مخصوص سرٹیفکیٹس۔

### 3. eIDAS سرٹیفکیٹس
**الیکٹرانک شناخت اور ٹرسٹ سروسز**

یورپی eIDAS ریگولیشن کے مطابق سرٹیفکیٹس۔

### 4. QSealC - اہل الیکٹرانک سیل سرٹیفکیٹ
**قانونی ہستیوں کے لیے الیکٹرانک سیل**

QSealC قانونی ہستیوں کے لیے ایک اہل الیکٹرانک سیل ہے۔

### 5. TPP کے لیے QWAC
**تھرڈ پارٹی فراہم کنندگان کے لیے مخصوص QWAC**

PSD2 ایکسٹینشنز کے ساتھ QWAC سرٹیفکیٹ۔

### 6. TPP کے لیے QSealC
**تھرڈ پارٹی فراہم کنندگان کے لیے الیکٹرانک سیل**

PSD2 ایکسٹینشنز کے ساتھ TPPs کے لیے اہل الیکٹرانک سیل۔

## 👥 کس کے لیے

CertTrust ان کے لیے ڈیزائن کیا گیا ہے:

### 🏦 مالیاتی ادارے
- **تجارتی بینک** - محفوظ تصدیق اور PSD2 تعمیل
- **ادائیگی کے ادارے (PI)** - API رسائی اور ادائیگی خدمات
- **الیکٹرانک منی انسٹی ٹیوشنز (EMI)** - الیکٹرانک منی اجراء
- **نیو بینکس** - جدید ڈیجیٹل خدمات

### 🔄 تھرڈ پارٹی فراہم کنندگان (TPP)
- **AISP** - اکاؤنٹ کی معلومات کے خدمات فراہم کنندگان
- **PISP** - ادائیگی کے آغاز کے خدمات فراہم کنندگان
- **ASPSP** - اکاؤنٹ سروسنگ PSP
- **ایگریگیٹرز** - مالی ایگریگیشن خدمات

### 💼 کمپنیاں اور تنظیمیں
- **فن ٹیک** - مالیاتی شعبے میں اسٹارٹ اپس
- **کارپوریٹ** - مالی ضروریات والی بڑی کمپنیاں
- **عوامی انتظامیہ** - یورپی عوامی ادارے
- **انشورنس** - انشورنس کمپنیاں

## 🚀 انسٹالیشن

### ضروریات

شروع کرنے سے پہلے، یقینی بنائیں کہ آپ کے پاس نصب ہے:

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0 (یا yarn >= 1.22.0)
- **Git** (اختیاری)

### تیز انسٹالیشن

```bash
# ریپوزیٹری کلون کریں
git clone https://github.com/yourusername/certtrust.git

# پروجیکٹ ڈائریکٹری میں جائیں
cd certtrust

# انحصار انسٹال کریں
npm install

# ڈیولپمنٹ سرور شروع کریں
npm run dev
```

ایپلیکیشن `http://localhost:5173` پر دستیاب ہوگی

### پروڈکشن بلڈ

```bash
# پروڈکشن بلڈ
npm run build

# بلڈ کا پیش نظارہ
npm run preview
```

## 🔐 سیکیورٹی اور تعمیل

### سیکیورٹی معیارات

#### 🔒 خفیہ کاری
- **الگورتھم**: RSA 2048/4096 بٹس، ECDSA
- **ہیش**: SHA-256، SHA-384، SHA-512
- **پروٹوکول**: TLS 1.2، TLS 1.3
- **سرٹیفکیٹس**: X.509 v3

#### 📋 ضابطہ تعمیل

**eIDAS (EU ریگولیشن نمبر 910/2014)**
- الیکٹرانک شناخت
- اہل ٹرسٹ سروسز
- سرحد پار شناخت

**PSD2 (ادائیگی خدمات ہدایت 2)**
- مضبوط کسٹمر تصدیق (SCA)
- مشترکہ اور محفوظ مواصلات (CSC)

### ڈیٹا کا تحفظ

- **GDPR مطابقت**: جنرل ڈیٹا پروٹیکشن ریگولیشن کی پابندی
- **ڈیٹا خفیہ کاری**: تمام حساس ڈیٹا خفیہ ہے
- **محفوظ منتقلی**: TLS کے ساتھ محفوظ مواصلات
- **پرائیویسی بائی ڈیزائن**: پرائیویسی پر مبنی فن تعمیر
