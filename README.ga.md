## 🎯 Forbhreathnú

Is ardán gréasáin nua-aimseartha, gairmiúil é **CertTrust** a ligeann do bhainc, institiúidí íocaíochta, TPP (Soláthraithe Tríú Páirtí) agus eagraíochtaí airgeadais teastais dhigiteacha cáilithe a fháil **saor in aisce** i **dtimpeallacht táirgthe**.

Murab ionann agus réitigh eile a sholáthraíonn teastais tástála nó bosca gainimh amháin, eagraíonn CertTrust teastais fhíora, réidh le húsáid láithreach le haon institiúid baincéireachta agus airgeadais san Eoraip, comhlíontach le rialacháin **PSD2** agus **eIDAS**.

### Cén fáth CertTrust?

| Gné | CertTrust | Seirbhísí Eile |
|-----|-----------|----------------|
| Timpeallacht | ✅ **Táirgthe** | ❌ Tástáil/Bosca Gainimh |
| Bailíocht | ✅ **Gach institiúid AE** | ⚠️ Teoranta |
| Costas | ✅ **Saor in Aisce** | ❌ Íoctha |
| Comhlíonadh | ✅ **PSD2 + eIDAS** | ⚠️ Páirteach |
| Eisiúint | ✅ **Láithreach** | ❌ Laethanta/seachtaine |

## ✨ Príomhghnéithe

### 🏭 Timpeallacht Táirgthe Fíor
- Teastais eisithe i dtáirgthe, ní i dtimpeallacht tástála
- Réidh le húsáid láithreach le API baincéireachta fíora
- Luach dlíthiúil iomlán ar fud an Aontais Eorpaigh

### 🏦 Bailíocht Uilíoch
- Glactha ag **gach institiúid airgeadais** san Eoraip
- Bainc tráchtála, institiúidí íocaíochta, ASPSP, AISP, PISP
- Finteic, neamhbhainc, árachas, riarachán poiblí

### ⚡ Eisiúint Láithreach
- Faigh teastais laistigh de nóiméid
- Gan próiseas ceadaithe fada
- Íoslódáil láithreach tar éis bailíochtú cód

### 🔒 Slándáil Uasta
- Eochracha cripteagrafacha 2048/4096 giotán
- Algartaim SHA-256 agus níos airde
- Eisithe ag QTSP údaraithe (Soláthraí Seirbhíse Iontaobhas Cáilithe)

### 🇪🇺 Comhlíonadh Eorpach
- 100% comhlíontach le Rialachán eIDAS (AE) Uimh. 910/2014
- Comhlíonadh iomlán le PSD2 (Treoir um Sheirbhísí Íocaíochta 2)
- Urram do chaighdeáin EBA (Údarás Baincéireachta Eorpach)

### 💰 100% Saor in Aisce
- Gan costais i bhfolach
- Gan síntiús
- Cuir isteach an cód agus faigh gach teastas

## 📜 Teastais atá ar Fáil

### 1. QWAC - Teastas Fíordheimhnithe Suíomh Gréasáin Cáilithe
**Fíordheimhniú slán suíomh gréasáin**

Is teastas digiteach cáilithe é QWAC a fhíordheimhníonn aitheantas suíomh gréasáin agus a ráthaíonn cumarsáidí slána TLS/SSL.

### 2. Teastais PSD2
**Teastais do Sholáthraithe Tríú Páirtí**

Teastais shonracha do TPPanna atá ag oibriú faoi Threoir um Sheirbhísí Íocaíochta 2.

### 3. Teastais eIDAS
**Aitheantas Leictreonach agus Seirbhísí Iontaobhais**

Teastais chomhlíontach le rialachán eIDAS Eorpach le haghaidh aitheantas leictreonach agus seirbhísí iontaobhais cáilithe.

### 4. QSealC - Teastas Séala Leictreonaigh Cáilithe
**Séala leictreonach do phearsana dlí**

Is séala leictreonach cáilithe é QSealC do phearsana dlí. Ráthaíonn sé bunús agus sláine doiciméad leictreonach le luach dlíthiúil ar fud an AE.

### 5. QWAC do TPP
**QWAC sonrach do Sholáthraithe Tríú Páirtí**

Teastas QWAC le leathnú PSD2 i réimsí pribhléide.

### 6. QSealC do TPP
**Séala leictreonach do Sholáthraithe Tríú Páirtí**

Séala leictreonach cáilithe do TPPanna le leathnú PSD2.

## 👥 Cé dó é

Tá CertTrust deartha do:

### 🏦 Institiúidí Airgeadais
- **Bainc Tráchtála** - Fíordheimhniú slán agus comhlíonadh PSD2
- **Institiúidí Íocaíochta (PI)** - Rochtain API agus seirbhísí íocaíochta
- **Institiúidí Airgid Leictronaigh (EMI)** - Eisiúint airgid leictronaigh
- **Neamhbhainc** - Seirbhísí digiteacha nuálacha

### 🔄 Soláthraithe Tríú Páirtí (TPP)
- **AISP** - Soláthraithe Seirbhíse Faisnéise Cuntais
- **PISP** - Soláthraithe Seirbhíse Tionscnaimh Íocaíochta
- **ASPSP** - PSP Freastail Cuntais
- **Comhtháthaitheoirí** - Seirbhísí comhtháthaithe airgeadais

### 💼 Cuideachtaí agus Eagraíochtaí
- **Finteic** - Tosaigh agus scálaigh suas sa earnáil airgeadais
- **Corparáideach** - Cuideachtaí móra le riachtanais airgeadais
- **Riarachán Poiblí** - Eintitis phoiblí Eorpacha
- **Árachas** - Cuideachtaí árachais

## 🚀 Suiteáil

### Réamhriachtanais

Roimh thosú, cinntigh go bhfuil suiteáilte agat:

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0 (nó yarn >= 1.22.0)
- **Git** (roghnach)

### Suiteáil Thapa

```bash
# Clónaigh an stór
git clone https://github.com/yourusername/certtrust.git

# Téigh isteach san fhillteán tionscadail
cd certtrust

# Suiteáil spleáchais
npm install

# Tosaigh an freastalaí forbartha
npm run dev
```

Beidh an feidhmchlár ar fáil ag `http://localhost:5173`

### Tógáil Táirgthe

```bash
# Tógáil táirgthe
npm run build

# Réamhamharc na tógála
npm run preview
```

## 🔐 Slándáil agus Comhlíonadh

### Caighdeáin Slándála

#### 🔒 Criptiú
- **Algartaim**: RSA 2048/4096 giotán, ECDSA
- **Haiseáil**: SHA-256, SHA-384, SHA-512
- **Prótacail**: TLS 1.2, TLS 1.3
- **Teastais**: X.509 v3

#### 📋 Comhlíonadh Rialála

**eIDAS (Rialachán AE Uimh. 910/2014)**
- Aitheantas leictreonach
- Seirbhísí iontaobhais cáilithe
- Aitheantas trasteorann

**PSD2 (Treoir um Sheirbhísí Íocaíochta 2)**
- Fíordheimhniú Láidir Custaiméara (SCA)
- Cumarsáid Choiteann agus Shlán (CSC)

### Cosaint Sonraí

- **GDPR Comhlíontach**: Urram don Rialachán Ginearálta um Chosaint Sonraí
- **Criptiú Sonraí**: Tá gach sonraí íogair criptithe
- **Tarchur Slán**: Cumarsáidí cosanta le TLS
- **Príobháideacht de réir Dearaidh**: Ailtireacht atá dírithe ar phríobháideacht

## ❓ CC

**C: An bhfuil na teastais saor in aisce i ndáiríre?**
F: Tá, tá na teastais 100% saor in aisce. Cuir isteach an cód bolscaireachta agus faigh gach teastas gan aon chostas.

**C: An bhfuil na teastais i dtáirgthe nó i dtástáil?**
F: Tá na teastais i **dtimpeallacht táirgthe fíor**. Ní teastais bosca gainimh nó tástála iad.

**C: Do cé na hinstitiúidí atá na teastais bailí?**
F: Tá na teastais bailí do **gach institiúid airgeadais** san Eoraip: bainc, institiúidí íocaíochta, ASPSP, AISP, PISP, finteic, neamhbhainc, árachas, riarachán poiblí.

**C: An bhfuil na teastais aitheanta ar fud na hEorpa?**
