## 🎯 अवलोकन

**CertTrust** एक आधुनिक, पेशेवर वेब प्लेटफॉर्म है जो बैंकों, भुगतान संस्थानों, TPP (थर्ड पार्टी प्रोवाइडर्स) और वित्तीय संगठनों को **प्रोडक्शन वातावरण** में **मुक्त** योग्य डिजिटल प्रमाणपत्र प्राप्त करने की अनुमति देता है।

अन्य समाधानों के विपरीत जो केवल परीक्षण या सैंडबॉक्स प्रमाणपत्र प्रदान करते हैं, CertTrust वास्तविक प्रमाणपत्र जारी करता है, जो यूरोप में किसी भी बैंकिंग और वित्तीय संस्थान के साथ तत्काल उपयोग के लिए तैयार हैं, **PSD2** और **eIDAS** नियमों के अनुरूप।

### CertTrust क्यों?

| विशेषता | CertTrust | अन्य सेवाएं |
|---------|-----------|-------------|
| वातावरण | ✅ **प्रोडक्शन** | ❌ परीक्षण/सैंडबॉक्स |
| वैधता | ✅ **हर EU संस्थान** | ⚠️ सीमित |
| लागत | ✅ **मुफ्त** | ❌ सशुल्क |
| अनुपालन | ✅ **PSD2 + eIDAS** | ⚠️ आंशिक |
| जारी | ✅ **तत्काल** | ❌ दिन/सप्ताह |

## ✨ मुख्य विशेषताएं

### 🏭 वास्तविक प्रोडक्शन वातावरण
- प्रमाणपत्र प्रोडक्शन में जारी किए गए, परीक्षण वातावरण में नहीं
- वास्तविक बैंकिंग APIs के साथ तत्काल उपयोग के लिए तैयार
- यूरोपीय संघ भर में पूर्ण कानूनी मूल्य

### 🏦 सार्वभौमिक वैधता
- यूरोप के **सभी वित्तीय संस्थानों** द्वारा स्वीकृत
- वाणिज्यिक बैंक, भुगतान संस्थान, ASPSP, AISP, PISP
- फिनटेक, नियोबैंक, बीमा, सार्वजनिक प्रशासन

### ⚡ तत्काल जारी
- मिनटों में प्रमाणपत्र प्राप्त करें
- कोई लंबी मंजूरी प्रक्रिया नहीं
- कोड सत्यापन के बाद तत्काल डाउनलोड

### 🔒 अधिकतम सुरक्षा
- 2048/4096 बिट क्रिप्टोग्राफिक कुंजियां
- SHA-256 और उच्चतर एल्गोरिदम
- अधिकृत QTSP (योग्य ट्रस्ट सेवा प्रदाता) द्वारा जारी

### 🇪🇺 यूरोपीय अनुपालन
- eIDAS विनियमन (EU) संख्या 910/2014 के साथ 100% अनुपालन
- PSD2 (भुगतान सेवाएं निर्देश 2) के साथ पूर्ण अनुपालन
- EBA (यूरोपीय बैंकिंग प्राधिकरण) मानकों का पालन

### 💰 100% मुफ्त
- कोई छिपी हुई लागत नहीं
- कोई सदस्यता नहीं
- कोड दर्ज करें और सभी प्रमाणपत्र प्राप्त करें

## 📜 उपलब्ध प्रमाणपत्र

### 1. QWAC - योग्य वेबसाइट प्रमाणीकरण प्रमाणपत्र
**सुरक्षित वेबसाइट प्रमाणीकरण**

QWAC एक योग्य डिजिटल प्रमाणपत्र है जो वेबसाइट की पहचान को प्रमाणित करता है और सुरक्षित TLS/SSL संचार की गारंटी देता है।

### 2. PSD2 प्रमाणपत्र
**थर्ड पार्टी प्रोवाइडर्स के लिए प्रमाणपत्र**

भुगतान सेवाएं निर्देश 2 के तहत काम करने वाले TPPs के लिए विशिष्ट प्रमाणपत्र।

### 3. eIDAS प्रमाणपत्र
**इलेक्ट्रॉनिक पहचान और ट्रस्ट सेवाएं**

यूरोपीय eIDAS विनियमन के अनुरूप प्रमाणपत्र।

### 4. QSealC - योग्य इलेक्ट्रॉनिक सील प्रमाणपत्र
**कानूनी इकाइयों के लिए इलेक्ट्रॉनिक सील**

QSealC कानूनी इकाइयों के लिए एक योग्य इलेक्ट्रॉनिक सील है।

### 5. TPP के लिए QWAC
**थर्ड पार्टी प्रोवाइडर्स के लिए विशिष्ट QWAC**

PSD2 एक्सटेंशन के साथ QWAC प्रमाणपत्र।

### 6. TPP के लिए QSealC
**थर्ड पार्टी प्रोवाइडर्स के लिए इलेक्ट्रॉनिक सील**

PSD2 एक्सटेंशन के साथ TPPs के लिए योग्य इलेक्ट्रॉनिक सील।

### 7. QWAC SAN - Subject Alternative Name के साथ योग्य वेबसाइट प्रमाणीकरण प्रमाणपत्र
**मल्टी-डोमेन सुरक्षित वेबसाइट प्रमाणीकरण**

QWAC SAN एक योग्य डिजिटल प्रमाणपत्र है जो वेबसाइट की पहचान को प्रमाणित करता है और Subject Alternative Name (SAN) के माध्यम से कई डोमेन के समर्थन के साथ सुरक्षित TLS/SSL संचार की गारंटी देता है। एकल प्रमाणपत्र के साथ कई डोमेन और उप-डोमेन की सुरक्षा करने की अनुमति देता है।

## 👥 किसके लिए

CertTrust इनके लिए डिज़ाइन किया गया है:

### 🏦 वित्तीय संस्थान
- **वाणिज्यिक बैंक** - सुरक्षित प्रमाणीकरण और PSD2 अनुपालन
- **भुगतान संस्थान (PI)** - API पहुंच और भुगतान सेवाएं
- **इलेक्ट्रॉनिक मनी संस्थान (EMI)** - इलेक्ट्रॉनिक मनी जारी
- **नियोबैंक** - नवीन डिजिटल सेवाएं

### 🔄 थर्ड पार्टी प्रोवाइडर्स (TPP)
- **AISP** - खाता जानकारी सेवा प्रदाता
- **PISP** - भुगतान आरंभ सेवा प्रदाता
- **ASPSP** - खाता सर्विसिंग PSP
- **एग्रीगेटर्स** - वित्तीय एग्रीगेशन सेवाएं

### 💼 कंपनियां और संगठन
- **फिनटेक** - वित्तीय क्षेत्र में स्टार्टअप
- **कॉर्पोरेट** - वित्तीय जरूरतों वाली बड़ी कंपनियां
- **सार्वजनिक प्रशासन** - यूरोपीय सार्वजनिक संस्थाएं
- **बीमा** - बीमा कंपनियां

## 🚀 स्थापना

### पूर्वापेक्षाएं

शुरू करने से पहले, सुनिश्चित करें कि आपके पास स्थापित है:

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0 (या yarn >= 1.22.0)
- **Git** (वैकल्पिक)

### त्वरित स्थापना

```bash
# रिपॉजिटरी क्लोन करें
git clone https://github.com/yourusername/certtrust.git

# प्रोजेक्ट डायरेक्टरी में जाएं
cd certtrust

# निर्भरताएं स्थापित करें
npm install

# डेवलपमेंट सर्वर शुरू करें
npm run dev
```

एप्लिकेशन `http://localhost:5173` पर उपलब्ध होगा

### प्रोडक्शन बिल्ड

```bash
# प्रोडक्शन बिल्ड
npm run build

# बिल्ड का पूर्वावलोकन
npm run preview
```

## 🔐 सुरक्षा और अनुपालन

### सुरक्षा मानक

#### 🔒 एन्क्रिप्शन
- **एल्गोरिदम**: RSA 2048/4096 बिट, ECDSA
- **हैश**: SHA-256, SHA-384, SHA-512
- **प्रोटोकॉल**: TLS 1.2, TLS 1.3
- **प्रमाणपत्र**: X.509 v3

#### 📋 नियामक अनुपालन

**eIDAS (EU विनियमन संख्या 910/2014)**
- इलेक्ट्रॉनिक पहचान
- योग्य ट्रस्ट सेवाएं
- सीमा पार मान्यता

**PSD2 (भुगतान सेवाएं निर्देश 2)**
- मजबूत ग्राहक प्रमाणीकरण (SCA)
- सामान्य और सुरक्षित संचार (CSC)

### डेटा सुरक्षा

- **GDPR अनुपालन**: सामान्य डेटा सुरक्षा विनियमन का पालन
- **डेटा एन्क्रिप्शन**: सभी संवेदनशील डेटा एन्क्रिप्टेड है
- **सुरक्षित संचार**: TLS के साथ सुरक्षित संचार
- **प्राइवेसी बाय डिज़ाइन**: गोपनीयता-उन्मुख वास्तुकला

## ❓ सामान्य प्रश्न

**प्र: क्या प्रमाणपत्र वास्तव में मुफ्त हैं?**
उ: हां, प्रमाणपत्र 100% मुफ्त हैं। प्रचार कोड दर्ज करें और बिना किसी लागत के सभी प्रमाणपत्र प्राप्त करें।

**प्र: क्या प्रमाणपत्र प्रोडक्शन में हैं या परीक्षण में?**
उ: प्रमाणपत्र **वास्तविक प्रोडक्शन वातावरण** में हैं। ये सैंडबॉक्स या परीक्षण प्रमाणपत्र नहीं हैं।

**प्र: प्रमाणपत्र किन संस्थानों के लिए मान्य हैं?**
उ: प्रमाणपत्र यूरोप के **हर वित्तीय संस्थान** के लिए मान्य हैं: बैंक, भुगतान संस्थान, ASPSP, AISP, PISP, फिनटेक, नियोबैंक, बीमा, सार्वजनिक प्रशासन।

**प्र: क्या प्रमाणपत्र पूरे यूरोप में मान्यता प्राप्त हैं?**
उ: हां, eIDAS प्रमाणपत्र यूरोपीय संघ के सभी 27 सदस्य राज्यों में स्वचालित रूप से मान्यता प्राप्त हैं।
